🎬 MuseTalk avatar service

Set up a persona from an initial video, then send a wav and watch the avatar react.

1 · Set up a persona (from an initial video)

2 · Test: send a wav → see the avatar speak

3 · Live: speak into the mic → watch the avatar follow

Uses the persona selected above. The browser only allows the mic on a secure context — open this page via http://localhost:8000 through an SSH tunnel (see the deploy doc §6b). The avatar idles while you're silent and lip-syncs ~1 window (MUSETALK_WINDOW_SEC) behind your voice.
